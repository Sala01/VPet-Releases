# Credits

VPetWear and VPetFarm are modified versions of open source projects. All of the work below is
used under the MIT license, and the original copyright notices are kept in the `LICENSE` files.

## Original projects

- **VitalWear** by Christopher O'Grady (cfogrady). A Wear OS engine reimplementation of the Vital
  Bracelet BE. VPetWear is a modified version of it.
  https://github.com/cfogrady/VitalWear
- **VBHelper** by nacabaro. VPetFarm is a modified version of it.
  https://github.com/nacabaro/vbhelper

## Libraries by the same authors

- **VB-DIM-Reader** (cfogrady): reads and writes DIM and BEM cards.
  https://github.com/cfogrady/VB-DIM-Reader
- **nearby-connections-p2p** (cfogrady): character transfer between devices.
  https://github.com/cfogrady/nearby-connections-p2p
- **lib-vb-nfc** (cfogrady): NFC communication with the Vital Bracelet.
  https://github.com/cfogrady/lib-vb-nfc
